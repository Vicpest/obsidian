# CSA

CSA = Carry-Save Adder，进位保存加法器。

## 功能

CSA 同时接收 `A`、`B`、`C` 三个同位宽操作数，输出部分和 `S` 与进位 `Carry`：`A + B + C = S + (Carry << 1)`。每一位只进行 3-2 压缩，不在本级传播进位；末级再由普通加法器完成进位传播。

## 在 NPU 里面哪里会出现 CSA

1. **整数乘法部分积压缩**：将乘法生成的多行部分积逐级压缩为两行。
2. **[[MAC]] / [[PE]] 内核**：提高 INT8、INT4 等乘法器的吞吐和时序余量。
3. **多操作数累加**：延后进位传播，缩短组合关键路径。

## 相关单元

- 压缩树末级需要进位传播加法器；[[MAC]] 是最常见的集成位置。
- 宽累加结果的动态缩放会使用 [[LZD]] 与 [[Barrel Shifter]]。

## 实现要点

- `Carry` 必须左移一位并保留最高位，避免溢出丢失。
- CSA 输出是冗余表示；用于比较、存储前通常必须完成最终相加。
