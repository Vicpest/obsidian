# LZD

LZD = Leading-Zero Detector，前导零检测器。
## 功能

输入一个位宽 N 比特无符号数，输出**高位连续 0 的个数**。

示例（32bit）：

- `0000_1010_xxxx…` → LZD 输出 = 4（前面 4 个 0）
- `1101_xxxx…` → LZD 输出 = 0（最高位直接是 1，没有前导零）
- `0000_0000` → 全零，输出等于位宽。

> 配套：**LOD Leading‑One Detector**：检测最高位 1 所在位置。 关系：`LOD_pos = (N‑1) − LZD_count`。

## 在 Transformer-NPU 里面哪里会出现 LZD

1. **浮点 / FP16/FP8 规格化**：尾数加减后高位出现一串 0，LZD 算出左移量，[[Barrel Shifter]] 移动尾数并修改指数。
2. **[[Softmax]] / [[Exp]] 硬件实现**：定点 exp 需要归一化输入，LZD/LOD 用来计算最高有效位的对齐移位量。

> Softmax 里的 exp 硬件通路，大量实例 LZD。

3. **[[RMSNorm]] / [[LayerNorm]] 归一化**：[[RSQRT]]、倒数硬件迭代需将输入规格化到 `[1, 2)` 区间，LZD 提供移位量。
4. **定点溢出 / 缩放逻辑**：[[MAC]] 输出很宽，LZD 可判断有效位，决定右移截断或动态量化的缩放量。

## 实现要点

- 全零输入应输出 `count = N`，并额外给出 `all_zero` 标志或等价编码。
- 输出位宽至少为 `ceil(log2(N + 1))`，以表示 N 位全零的情况。
- 宽数据路径宜采用树形或分组优先编码，避免串行扫描造成长组合路径。
