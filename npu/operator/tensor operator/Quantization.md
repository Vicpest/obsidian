# Quantization

量化将张量从一种数值表示映射为另一种表示，典型形式为 `q = round(x / scale) + zero_point`，反量化则执行近似逆变换。

## 功能

它使权重和激活可以使用 INT8、INT4、FP8 等较低位宽格式，以降低存储、带宽和 [[MAC]] 成本。

## 在 NPU 里面哪里会出现 Quantization

1. 低比特 GEMM 前的激活/权重格式转换与乘加后的重标定。
2. 逐张量、逐通道或逐组 scale 的权重量化。
3. 推理输出写回 DRAM 前的压缩，以及 KV Cache 的低比特存储。

## 实现要点

- 明确 scale 粒度、对称/非对称量化、舍入、饱和以及异常值策略。
- 使用 [[LZD]] 和 [[Barrel Shifter]] 可实现动态定点缩放；量化算子通常可与 [[GEMM]] 融合。
